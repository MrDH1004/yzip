yzip 설치 안내

이 프로그램이 컴퓨터에서 바꾸는 것
  - 사용자 계정에 설치됩니다 (관리자 권한 없음): %LOCALAPPDATA%\Programs\yzip
  - 탐색기 우클릭 메뉴에 yzip 항목(압축하기, 풀기)을 등록합니다.
  - 선택하면 압축 파일(.zip, .zipx, .tar, .lzh, .iso, .7z, .gz, .xz, .zpaq 등)을 yzip으로 열도록 연결합니다.
    자체 압축 EXE는 열 수 있지만 일반 실행 파일 전체를 연결하지는 않습니다.
    다른 프로그램이 이미 기본 앱이면 Windows 정책상 바뀌지 않으며, 설정 > 기본 앱에서 직접 고를 수 있습니다.
  - 제거하면 위 항목은 모두 원래대로 돌아갑니다 (설정 > 앱 > 설치된 앱 > yzip > 제거).

인터넷 사용 (개인정보)
  - "업데이트 자동 확인"을 켜 두면 프로그램을 열 때마다 GitHub(api.github.com)에서
    최신 버전 정보를 받아 옵니다. 이때 보내는 것은 일반 웹 요청 정보(IP 주소, 프로그램 버전이 담긴
    User-Agent)뿐이며, 파일 이름이나 압축 내용 등 다른 정보는 보내지 않습니다.
  - 업데이트를 고르면 GitHub에서 설치 파일을 내려받고 SHA-256으로 검증한 뒤 설치합니다.
  - 다음 화면에서 끌 수 있고, 설치 후에도 "더 보기 > 업데이트 자동 확인"에서 끌 수 있습니다.
  - 그 밖에는 사용자가 요청하지 않는 한 어떤 정보도 네트워크로 보내지 않습니다.

소스 코드와 개인정보 처리 방침: https://github.com/MrDH1004/yzip

압축 형식 처리
  - RAR/RAR5, ISO/UDF, CAB, LHA/CPIO/RPM/DEB는 포함된 libarchive.dll을 프로세스 안에서 처리합니다.
  - EGG/ALZ는 포함된 yzip_native.dll(Rust unegg/unalz)을 프로세스 안에서 처리합니다.
  - ZPAQ는 포함된 공개 소스 zpaq.exe 호환 리더로 목록·검사·해제를 처리합니다.
  - RAR/EGG/ALZ는 해제 전용이며 해당 포맷 생성 기능은 제공하지 않습니다. 암호화 RAR은 감지 후 안전하게 거부합니다.
