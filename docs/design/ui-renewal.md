# yzip 1.0.17 UI 갱신

## 목적

최신 지원 형식을 정확히 안내하고 홈·파일 목록·작업 창·환경설정의 시각적 구조를 일치시킨다.
파일 작업을 시작하고 결과를 확인하는 과정에 가장 많은 공간을 배정한다.

## 디자인 기준

- 배경 `#F4F6F7`, 작업 면 `#FFFFFF`, 본문 `#202D35`, 보조 `#64737D`, 경계 `#DCE3E6`, 강조 `#16776A`.
- Windows 시스템 글꼴 및 한국어 글꼴을 사용하며 기본 본문 10pt, 화면 제목 20~22pt, 보조 9pt.
- 사용자 글꼴 크기는 본문·제목의 비율을 유지하며 확대한다.
- 홈은 브랜드/설정/업데이트, 파일 작업 영역, 지원 형식 안내 순서로 구성한다.
- 생성 가능한 형식과 열기·해제만 지원하는 형식을 구분한다. RAR·EGG·ALZ 생성은 안내하지 않는다.
- 파일 목록은 압축 풀기를 주 동작으로 유지하고 이름 검색, 홈 이동, 환경설정을 쉽게 제공한다.
- 설정은 왼쪽의 8개 섹션 탐색과 오른쪽의 설정 항목, 하단 저장·취소로 구성한다.
- 포커스 표시, 최소 창 크기, 긴 파일명, 어두운 테마, 한국어·영어에서 가독성을 확인한다.
- 실제 화면 캡처 대신 앱 자체 오프스크린 렌더링을 사용한다. 다른 앱·모니터를 조회하지 않는다.

## 확인할 동작

- 홈의 열기·압축·환경설정·업데이트 버튼은 기존 동작으로 연결된다.
- ZIP·7Z·RAR·EGG·ALZ·TAR·ISO·CAB·ZIPX·LZH·ZPAQ 등 대표 형식이 안내된다.
- 파일 검색은 파일 내용이나 경로를 바꾸지 않고 현재 목록의 표시만 바꾼다.
- 숨긴 검색 결과가 선택 작업에 남지 않으며 폴더 이동·새 압축 파일 열기에 검색 상태가 일관된다.
- 환경설정 탐색은 저장되지 않은 확장자 선택을 보존한다.
- 업데이트 동의, 설정 저장 및 중복 파일 처리 동작을 보존한다.

## 1.0.18 크기 조정

- 기본 창은 960×680에서 640×454로 축소하고 최소 크기는 640×420으로 조정했다.
- 드롭 영역의 상하 늘어나는 여백을 없애고 기본 글꼴에서 약 155px 높이로 유지한다.
- 단축키 설명은 한 줄로 표시하며 큰 글꼴에서는 기존 세로 배치와 스크롤 접근을 유지한다.

## 1.0.19 파일 연결 단순화

- 파일 연결은 반복 제목·설명·검색·상단 전체 체크 없이 확장자 표부터 바로 시작한다.
- 표가 페이지의 남은 높이를 채우며 자체 스크롤만 사용한다. 기본 글꼴에서는 행 간격도 줄여 더 많은 형식을 보여준다.
- 확장자별 체크와 하단 전체 선택·해제 및 Windows 기본 앱 열기는 유지한다.
